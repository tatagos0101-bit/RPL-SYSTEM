# 2.3.7 Borrow and Return Transaction Flowchart - This flowchart shows how librarians use the Borrow / Return page to view transaction records, identify borrowing members, add ready reservations or scan copy codes, review selections, and confirm borrowing or return transactions.

Ready reservations use Add to list with an automatically selected available copy. Walk-in borrowing uses QR or manual code entry. Returns can start from a loan row or a copy lookup. Review and final confirmation are required.
