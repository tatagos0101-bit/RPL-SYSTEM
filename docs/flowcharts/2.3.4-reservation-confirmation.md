# 2.3.4 Reservation Confirmation Flowchart

The member selects Reserve, reviews an Are you sure? prompt, and confirms or cancels.
There is no facial scan or additional identity verification during confirmation.
The five-book combined allowance and ready-reservation pickup deadline remain.
This revision changes the diagram only; it does not alter application behavior.

```mermaid
flowchart TD
  s([Start]) --> cart[Display cart and reservations]
  cart --> click{User clicks Reserve?}
  click -->|No| e([End])
  click -->|Yes| prompt[Ask: Are you sure you want to reserve this book?]
  prompt --> confirm{User confirms?}
  confirm -->|No / Cancel| cart
  confirm -->|Yes| count[Count existing commitments plus selected books]
  count --> limit{Over five books?}
  limit -->|Yes| error[Show five-book maximum notice]
  error --> e
  limit -->|No| save[Create ready or queued reservation]
  save --> expiry[Set 24-hour pickup expiry if ready]
  expiry --> e
```

The allowance includes active/overdue loans and pending/ready reservations.
Queued requests receive their deadline on promotion to ready.
