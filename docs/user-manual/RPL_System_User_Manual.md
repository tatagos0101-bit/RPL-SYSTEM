# Rizal Provincial Library System User Manual

Edition 1.0
16 November 2026

A practical guide for public visitors, registered members, librarians, and entrance station operators.

# 1 Getting started
Use this manual to find books, manage reservations and accounts, issue and return copies, maintain inventory, prepare reports, print QR labels, and record attendance.

Use the library's web address and the correct portal. Staff register members; public browsing needs no account. Follow the controls shown in your website edition.

## Who can use each area
| User | Main functions |
| --- | --- |
| Public visitor | Search and browse books, inspect details and availability, and open member sign in or the privacy notice. |
| Registered member | Use the dashboard, recommendations, favorites, reservations, waitlist, permitted profile details, and password controls. |
| Librarian | Manage books, members, circulation, reservations, due books, reports, copy labels, and station access. |
| Entrance station operator | Unlock, start or pause attendance scanning, and review confirmed results. |

## Find a page
| Task | Location |
| --- | --- |
| Public browsing | Home, then Public Catalog or Browse Books; /browse. |
| Member sign in | Member Sign In; /user/login. |
| Librarian sign in | Staff portal sign in; /librarian/login. |
| Attendance | Entrance Station; /entry-station. |

Select the menu icon to reveal navigation. The librarian sidebar starts hidden on all screens. Close the menu after choosing a page.

Use Previous and Next to change pages. Catalog controls appear above and below results. Scroll wide tables sideways. Public computer catalogs form vertical grids; phone shelves and member Featured collections scroll sideways.

**Before beginning:** Keep an internet connection available. Allow camera access only for camera features. Cameras normally require a secure website or a local demonstration address. Have the correct account credentials ready. A station PIN is separate from an account password.

# 2 Using the public catalog
Visitors can inspect books without signing in. An availability label helps you plan a visit; it does not reserve a copy.

## Search from the landing page
1. Open the home page and enter a title or author in its search field.
2. Select the search button or submit the search.
3. Review the catalog results. The search is carried into the catalog, and matching title or author text is highlighted where displayed.
4. Adjust or clear the search to change the results.

## Browse a genre
1. Open the public catalog and find **Browse the stacks**.
2. Select a genre tile and review its matching books.
3. Select **All books** to return to the full catalog.
4. Use the page controls when more results are available.

Genre previews keep their own artwork when you change categories; All books retains a mixed preview. Genre names and counts depend on recorded inventory. For no matches, check spelling, shorten the search, try an author, or choose **Reset all filters** when offered.

## Inspect a book
1. Select **View details** on its card.
2. Read the title, author, genre, publication details, availability, and description when supplied.
3. Use previous and next book arrows to inspect other results. Supported desktop views also accept arrow keys; phone views support swiping.
4. Select **Close**, the close icon, or Escape in supported dialogs.

Details use a consistent viewing frame. Long descriptions scroll within the information panel. A missing cover does not mean the book is absent from the catalog.

Select **Login to Reserve** when offered. After member sign in, review the selected book in My Reservations. Opening a detail view or signing in does not complete a reservation. Librarians use staff circulation tools to issue books.

# 3 Signing in and recovering access
Use the portal intended for your account. A member account cannot open the librarian workspace.

## Password sign in
1. Open the member or librarian sign in page and select **Password**.
2. Enter the email address or RPL Member ID and the password.
3. Select the sign in button.
4. Wait for the dashboard or required password change screen.

## Replace a temporary password
New accounts and accounts given a temporary reset password must change it before using ordinary protected features.

1. Enter the current temporary password when requested.
2. Create and confirm a new password with **8 to 128 characters and at least one digit**, then submit.
3. Wait for confirmation, then use the new password.

New registration passwords are 10 characters long. A later librarian reset may produce a different length. Keep the password actually provided for that operation. Older sessions are signed out after a password change or reset.

## Face ID sign in
1. Make sure staff have enrolled your face, then open the correct portal and select **Face ID**.
2. Allow camera access and face the camera directly in even lighting.
3. Use a live face, not a photograph or another screen.
4. Wait for a successful match and redirection.

Move closer if too far away and improve lighting if too dark. If live-face verification is uncertain or unavailable, use Password sign in. Ask staff about repeated recognition failure.

## Forgotten password
1. Select the member password recovery link and enter your email address or RPL Member ID.
2. Select **Send Reset Code** and retrieve the six-digit code from your verified email when sending is available.
3. Enter the code, a valid new password, and its confirmation.
4. Submit the reset and return to sign in.

Recovery uses a previously verified email. A registration email is not automatically verified, and registration SMS does not enable SMS password recovery. If the page requests librarian help, the verified mailbox is inaccessible, or delivery is unavailable, visit the librarian for supervised recovery. Codes expire and are single use; follow the displayed waiting period before requesting another.

# 4 Using the member dashboard
Open **Dashboard** to review current borrowing, due dates, recorded reading activity, and library visits. Read incomplete-data messages before relying on totals.

## Review loans and due dates
1. Review the current borrowing cards and loan list.
2. Check each title and due date.
3. Act on Due Soon and Overdue notices.
4. Bring books to the counter for the librarian to record their return.

A member cannot complete a physical return by closing a card or reporting an issue. The loan remains outstanding until the staff return operation is confirmed.

## Report a loan problem
1. Find the affected loan and select **Report Issue**.
2. Choose damaged book, wrong book issued, lost book, or other issue.
3. Add useful notes if needed.
4. Submit and wait for confirmation.

A report does not return the book, replace the copy, or settle an assessment. Ask the librarian how to proceed. Book-condition photo capture is not part of this workflow.

## Reading activity and goals
Reading sections show recorded borrowing, genre distribution, and visits. A visit is an attendance record, not a measurement of reading a particular book. Empty charts can mean no relevant activity has been recorded.

1. Open the goals section and select **Set Goals**.
2. Enter targets for **Books This Year**, **Unique Genres**, and **Library Visits**.
3. Select **Save Goals**.
4. Review the saved targets and progress.

Changing a goal does not create borrowing or attendance records.

## Notifications
Open the bell to read messages, including reservation readiness. Mark messages as read or use **Mark all as read** when offered. Reading a message does not collect a book or complete a loan.

If dashboard information cannot load, use its retry control. A failed request does not prove that there are no loans or reservations.

# 5 Browsing and reserving books
Open **Browse Books** after signing in. Member browsing adds recommendations, favorites, selection controls, and reservation status.

## Featured collections
| Collection | Meaning |
| --- | --- |
| Recommended for you | Suggestions for members with borrowing history, using recorded borrowing and related interests. |
| Trending | Books ordered using recent borrowing activity. New members see this prominently. |
| What's new | Books most recently added to the catalog. |
| Books we love | Books members marked as favorites; this is not a star-rating feature. |

Scroll Featured shelves sideways. Use jump links between collections and **See all** where available. Suggestions do not guarantee availability.

## Search sort and favorites
1. Search by title or author, or select a genre under Browse the stacks.
2. In a genre or full-list view, open the sort menu.
3. Choose **Trending**, **Newest**, **Most loved**, or **Title**, as available.
4. Use the top or bottom page controls for more results.

Select the heart to add a favorite; select it again to remove it. Favorites influence discovery but do not reserve a book.

## Build a selection
1. Open a book or its card and select **Reserve** or its reservation action.
2. Continue selecting titles within the available allowance.
3. Select the **reserved** count button or **My Reservations**.
4. Review **My Selection** and remove unwanted titles.

**My Selection is a draft.** Books are not held until confirmation. The reserved count can include draft selections and existing reservations; inspect My Reservations to see each actual state.

## Confirm a reservation
1. Check each selected title and the Summary.
2. For an unavailable title, select the agreement to queue it if you wish to wait.
3. Make sure the selection fits the remaining allowance.
4. Select **Confirm Reservation**.
5. Wait for results and review the confirmed reservation list.

If confirmation is uncertain, use **Retry confirmation safely** when offered. Inspect individual results rather than assuming that every selected title succeeded.

## Five book allowance
Outstanding loans, ready reservations, and queued reservations count together toward a **five-book limit**. Two borrowed books and one ready reservation leave capacity for two more commitments. Draft selections become server reservations only after confirmation.

Return a loan or cancel an active reservation to free capacity. Overdue books or a suspended account can prevent further borrowing. Restrictions and availability are rechecked at confirmation.

## Reservation states
| State | Next action |
| --- | --- |
| My Selection | Review the draft and confirm if wanted. |
| In Queue or My Waitlist | Wait for availability and monitor queue position and notifications. |
| Ready for Pickup | Collect the book at the counter before the displayed deadline. |
| Fulfilled | The librarian issued the book as a loan; check its due date. |
| Cancelled or expired | The reservation is no longer active; make a new request only if needed. |

Ready books must be collected within **24 hours** of becoming ready. Follow the Philippine-time deadline; refreshing does not extend it. A queued reservation is not ready to borrow. Readiness concerns a title and does not permanently assign a particular physical copy.

To cancel, select the reservation's Cancel or close control and confirm. For pickup, visit the counter and let staff verify your identity through the supported supervised method.

# 6 Managing a member profile
Open **Profile** to view personal information, membership details, security, and Face ID status.

## Edit contact information
1. Select **Edit Profile**.
2. Update the editable phone and address or location fields.
3. Review the changes and select the save control.
4. Wait for confirmation.

Your verified name is read only and cannot be changed through Edit Profile. Ask the librarian about a correction. Member ID, role, and account status are not member-editable identity fields.

## Change and verify email
1. Select **Change email** in the email section.
2. Enter the new address and current password.
3. Select **Save email**.
4. Select **Verify email for password recovery**.
5. Confirm the current password, select **Send code**, and retrieve the code from the saved address.
6. Enter the six-digit code and select **Confirm code**.
7. Check for the Verified email message.

Changing an address removes its previous verification. Use an address you own and can access. Follow the waiting period before **Send another code**. Ask staff if sending is unavailable. Adding a phone does not make it a verified recovery channel.

## Profile photos
1. Select the photo or initials control.
2. Choose JPG, PNG, or WebP, no larger than **5 MB**.
3. Wait for **Profile photo saved**.
4. Use **Change photo** to replace it.
5. Select **Remove photo** to remove it, then wait for confirmation.

A photo is optional. Removal returns the normal initials or default appearance. A profile photo is separate from biometric face enrollment; removing it does not remove Face ID.

## Password and Face ID
Use the password change section to enter the current password, a valid new password, and its confirmation. Submit and wait for success. Other devices with old sessions will need to sign in again.

Face ID status shows active enrollment or Not Enrolled. Library staff manage enrollment, replacement, and deletion. A profile photo upload does not enroll Face ID.

# 7 Using the librarian dashboard
Sign in to the librarian portal, open **Home** or **Dashboard**, and use the menu icon if navigation is hidden.

## Review the overview
1. Select the period and dates.
2. Select **Refresh overview** after changing the relevant controls.
3. Review attendance, circulation, patrons, and collection measures.
4. Select a measure or chart link to explore supporting records in Reports.
5. Review **Needs attention** for follow-up.

The overview includes recent activity, collection and demand, previous-period trends, and acquisition summaries where data exists. A current snapshot describes the present state, while a period chart describes activity during the chosen dates. Historical borrows remain borrowing activity after return.

## Staff notifications
Open the bell and inspect messages. Verify the related member, loan, or reservation before acting. Mark a message as read or use the all-read control as appropriate. Reading it does not resolve a loan issue or change stock.

Use Browse Books for inventory, Users for members, Borrow / Return for circulation, Reservations for queues, Due Books for outstanding loans, Reports for analysis, Add Book for new records, Print QR for labels, and Settings for account and station controls.

If data fails to load, refresh or retry. Missing information should not be treated as a zero total.

# 8 Registering and managing members
Open **Users** to search and inspect a member's identity, location, joining date, loans, Face ID state, and account status.

## Register a member
1. Select **Register Member** from Users or the dashboard registration control.
2. Enter full name and address or barangay; these are required.
3. Add email and phone when available; both contact fields are optional.
4. Optionally attach a government ID image using the accepted types and size limit shown by the form.
5. Review the details with the member and submit.
6. Wait for the result and record the Member ID.
7. Review password delivery and arrange the handoff.

An ID upload is not required to submit registration. After an uncertain result, search for the member before creating another account. Duplicate email or conflicting information can be rejected.

## Temporary password delivery
| Contact available | Delivery choice |
| --- | --- |
| Email supplied | Email delivery is attempted first. |
| No email but phone supplied | Registration SMS is attempted if configured. |
| Neither supplied | Librarian receives a password for private handoff. |
| Service unavailable or failed | Use the displayed librarian fallback password and arrange a private handoff. |

New registration passwords contain 10 characters. Accepted delivery does not prove receipt. A successfully accepted send normally hides the password from the response; use supervised recovery if the member cannot obtain it.

The system does not automatically switch a failed email attempt to a different phone. Contact entry and receipt of registration credentials do not verify email for recovery. Ask the member to replace the temporary password at first sign in and verify their own email from Profile.

## Register or reset Face ID
1. Find and verify the member.
2. Open actions and choose **Register Face** or **Reset Face Data**.
3. Explain the biometric notice and follow the approved verification process.
4. Allow the camera, position the live member, and select **Capture**.
5. Inspect the image; use **Retake** if needed.
6. Select **Enroll** or **Reset Face Data** and wait for success.
7. Select **Done**.

Existing enrollment remains until replacement succeeds. Improve lighting or use the supervised alternative if checks fail. Starting a camera is not an individual consent record.

## Password and account status
For assisted recovery, open the verified member's actions, select **Reset Password**, confirm as prompted, and privately hand over the new temporary password. It must be changed at sign in and invalidates old sessions.

Select **Suspend** or **Reactivate** in the member actions to change status. Wait for confirmation and refresh before repeating an uncertain change. Suspension does not settle outstanding loans.

## Delete face data or an account
Follow the library's approved request and identity checks before these permanent actions.

- **Delete Face Data** removes enrolled templates and linked face snapshots and signs the member out. The account and library history remain; password sign in remains available.
- **Delete Account** removes personal details, private ID and avatar uploads, and face data, cancels reservations, and signs the member out. Completed loan and attendance history is retained without identity.

The dialog requires the librarian's current password and typing **DELETE**. An account with outstanding books is blocked from deletion until they are returned. Account deletion cannot be undone.

# 9 Managing the book catalog
## Browse and inspect inventory
1. Open **Browse Books** in the librarian menu.
2. Search for the title or author and use the category or acquisition-source filter as needed.
3. Use pagination and scroll a wide table sideways to reveal columns and actions.
4. Select **View details** to inspect the cover, title, author, category, year, ISBN, shelf, copy count, library title code, and description.
5. Close the preview to return to the list.

View details is read only. Rows also provide Edit, cover upload, and Delete. The former inventory Acquisitions button is removed; acquisition metadata is maintained through Reports.

## Add one book manually
1. Open **Add Book** and select manual entry.
2. Enter title and author, choose or enter a category, and complete the details requested by the form.
3. Enter the verified copy quantity and shelf or location; add year and ISBN when known.
4. Supply a cover URL or a supported cover image if available.
5. Optionally write a **Book description**, visible in the public and member catalog.
6. Select the add or save button and wait for confirmation.

Descriptions allow **2,000 characters**. Do not enter private member information in a public description. Acquisition details are not required in Add Book.

## ISBN Auto Fill
1. Enter ISBN-10 or ISBN-13 in **ISBN Auto-Fill** and run the lookup.
2. Verify the returned title, author, year, cover, and suggested category against the physical book.
3. If a summary was found, select **Use online summary** to copy it into Book description.
4. Edit it or write your own description when no summary is available.
5. Complete the remaining fields and save.

A lookup prepares information but does not add the book. External records can be incomplete, so verify them before saving.

## Multiple ISBN lookup
1. Select **ISBN Bulk Lookup**.
2. Upload XLSX or CSV with an ISBN column, or paste one ISBN per line or separated by commas. Without an ISBN heading, the reader uses the first column.
3. Select **Look Up All ISBNs**.
4. Review found, failed, and already processed results. Correct or remove unwanted results when permitted.
5. Select records to add and set the intended copy quantity.
6. Select **Add Selected Books to Catalog** and review the outcome counts.
7. Use **Done** to clear a completed batch before preparing another.

A successful lookup is separate from a successful import. Do not delete or resubmit an unconfirmed result just to remove its warning; use the offered recovery controls.

## Import complete records
1. Select **Upload File**.
2. Prepare **XLSX** with the headings shown by the page: Title, Author, Category, Year, ISBN, Copies, Location, and Cover URL as applicable. Supported optional description headings can be included.
3. Convert legacy XLS to XLSX first. Full inventory import is different from an ISBN-list CSV lookup.
4. Choose a file no larger than **10 MB**.
5. Select **Process & Import**.
6. Review added books, duplicate ISBNs skipped, and rejected rows.
7. Correct rejected rows and check existing inventory before repeating a batch.

For an uncertain workbook result, use **Recover workbook result**. For an uncertain manual add, use **Recover saved book request**. A cover can fail after the book is saved; choose **Retry cover upload** for that saved record rather than adding it again.

## Edit covers and records
Select **Edit** on the correct row, update available fields, and save. Use the cover action to replace artwork. Change quantities only after checking physical stock. A quantity edit is not a loan or return.

Deleting a title is a separate action. Verify the record and read any history or availability rejection. Do not delete a record or reuse an old label to correct a loan.

## Category review
From Add Book, open **Librarian category review**. Inspect an unmatched label, choose a master category, and select **Apply mapping**. Use Previous labels or Next labels for additional records. This organizes catalog labels; it does not create stock.

# 10 Borrowing and returning books
Librarians confirm all circulation. **Borrow Books** and **Return Books** are separate starting actions. Scanning looks up records and builds a pending list; only final confirmation records a loan or return.

## Identify the borrowing member
1. Open **Borrow / Return** and select **Borrow Books**.
2. Choose **Manual ID** or **Face recognition**.
3. For Manual ID, enter the full Member ID, exact email, phone, or numeric user ID and select **Identify member**.
4. For face recognition, position the enrolled live member and perform identification.
5. Check the displayed name, Member ID, and allowance.

Manual ID is a supervised process. A name fragment or similar search result is not adequate identity verification.

## Issue a ready reservation
1. Review **Member reservations**, loaded automatically after identification.
2. Find a title marked **Ready for pickup** and check its deadline.
3. Read the automatically selected available copy number and code.
4. Select **Add to list**. QR scanning is optional for a ready reservation.
5. If another available copy will be handed over, use **Change copy** when offered and choose that exact copy before adding it.
6. Repeat for other ready titles, then select **Review list**.
7. Match the listed copy codes to the physical books.
8. Select **Confirm Borrowing** and wait for a confirmed transaction and due date for each item.

A queued reservation cannot be issued with the ready-reservation button. If no copy is available or loading fails, use Refresh copies or Refresh reservations and verify stock. Copy availability is checked again at confirmation.

## Issue a walk in loan
1. Identify the member.
2. With no active reservations, use the displayed scanner or code-entry controls.
3. If reservations exist but another title is needed, select **Scan or enter another book**.
4. Scan the physical-copy QR with a camera or USB scanner, or enter the code and select **Look up**.
5. If a legacy title code offers several candidates, choose the exact physical copy being handed over.
6. Add remaining books, select **Review list**, and verify member and copy details.
7. Select **Confirm Borrowing** and inspect every result.

Use the library copy code, not an ISBN or arbitrary URL. The server checks availability, an existing loan for the same title, overdue restrictions, suspension, and the combined five-book allowance.

## Return books
1. Select **Return Books**, or the return action on the correct outstanding-loan row.
2. Scan or enter the copy code.
3. If a legacy title offers several active loans, select the exact loan, member, and copy being returned.
4. Review the pending list and select **Review list** if needed.
5. Verify each title, member, copy, and loan reference.
6. Select **Confirm Returns**.
7. Wait for each confirmed return before treating the operation as complete.

A return closes the original loan and retains its history. The confirmed due date is authoritative. The application default loan period is 14 days, but the deployed configuration can differ; follow the actual loan date.

## Scanning options
| Method | How to use it |
| --- | --- |
| USB scanner | Focus Library QR code and scan with a device configured to send Enter. |
| Manual entry | Type the full library code and select Look up. |
| Camera | Select Start QR camera, allow permission, and choose the camera when needed. Use Stop camera when finished. |

QR images are decoded on the device. Face identification is a separate feature with different processing and privacy requirements.

## Mixed and unknown outcomes
Each item is recorded separately. A confirmed item remains confirmed if a later item fails. A multi-book list is not one all-or-nothing transaction.

If **Unresolved requests** appears, use **Check outcome** before recording more items. Use **Retry original request** for that same operation when appropriate. Do not create a replacement transaction or clear browser storage to bypass recovery. A missing receipt does not prove failure. There is no offline transaction replay.

# 11 Monitoring due books and reservations
## Outstanding books
1. Open **Due Books**.
2. Use All, Due Soon, or Overdue and the member or book search.
3. Inspect the due date, member, and exact copy.
4. Use the return action only when the corresponding physical book is being returned.
5. Complete and confirm the return procedure in Chapter 10.

The page also exposes the broader loan list where available. Refresh after circulation changes if information is stale.

Overdue loans can block new borrowing. Verify the actual record before contacting a member through the library's approved process. The current due-book email or SMS reminder control is unavailable and does not provide automatic delivery.

Fine panels are hidden in this edition. If a report includes assessed fine values, they are assessments, not proof of payment. There is no online payment collection workflow.

## Reservation management
1. Open **Reservations**.
2. Filter all reservations, ready pickups, or queued requests.
3. Search member or title and check state, queue position, and deadline.
4. Refresh if the list may have changed.
5. Choose Cancel and confirm when cancellation is appropriate.
6. Issue ready books through Borrow / Return after identifying the member.

A queued request waits for title availability. Returns and cancellations can promote the next eligible request. A page refresh does not extend a ready deadline. Check the current list before promising a copy.

# 12 Reports and acquisition records
Reporting is available to librarians through **Reports**, displayed as **Reports & Analytics**.

## Report categories
| Category | Information |
| --- | --- |
| Library usage | Recorded entry and exit sessions and attendance summaries. |
| Patrons | Member records, status, registration scope, and period participation. |
| Circulation | Borrow and return records, outstanding or overdue snapshots, and return timing. |
| Collection | Catalog and copy information, current holdings, and recorded copy states. |
| Acquisitions | Verified source, date, donor or supplier, cost, and related copy metadata. |
| Inventory checks | Inventory records and consistency information exposed by the report. |

## Apply filters
1. Select Report category or a shortcut such as **Borrow / Return Records** or **Entry Gate Logs**.
2. Choose a period or From and Through dates in Philippine time.
3. Enter a search and expand **Filters for** the category when needed.
4. Add relevant member ID, category, author, ISBN, shelf, status, acquisition source, or date-scope filters.
5. Select **Apply filters**.
6. Review the applied filters, matching count, summaries, charts, and rows.
7. Use supported column-header sorting, Records per page, Previous, and Next.

Draft filters do not change previews or downloads until Apply filters is selected. Use **Reset filters** for category defaults.

For circulation, select the correct date basis: borrowing or return activity, borrow date, return date, or due date. Currently outstanding and overdue options are present snapshots. For collection or patrons, distinguish all recorded dates from records created in the chosen period.

## Export or print
1. Apply filters and inspect the preview.
2. Choose the export scope offered by the page, such as current page or all matching records.
3. Select **CSV**, **Excel**, **PDF**, or **Print**.
4. Wait for completion and check the file or print preview.
5. If a large export is rejected, narrow the dates or filters and retry. Use **Cancel export** to stop a pending export.

CSV output can arrive in a ZIP of report files. Allow a print-preview window when needed. A preview page is only its displayed rows; check scope before treating a download as a complete result. If records changed or the report context expired, refresh and apply again.

## Monthly report
Select Month and Year in **Monthly library report**, then **Download Monthly PDF**. These controls apply to the monthly PDF independently of preview filters. The PDF groups usage, circulation, patrons, collection, acquisitions, and inventory into sections.

## Record one acquisition
1. Choose **Acquisitions** and select **Record acquisition**.
2. Enter the existing numeric **Physical copy ID** and select **Look up copy**.
3. Verify the displayed title and copy. The numeric ID is different from a printed QR code.
4. Enter verified source, acquisition date, donor or supplier, reference, cost, and currency. Leave unknown information blank.
5. Select **Save acquisition metadata** and wait for success.

This attaches metadata to an existing copy. It does not create stock or change copy codes.

## Import acquisition metadata
1. Select **Import acquisition metadata** and download the CSV template if needed.
2. Prepare CSV or XLSX with the required copy identifiers and supported headings.
3. Use YYYY-MM-DD dates and stay within **500 rows and 1 MB**.
4. Upload for validation and inspect the preview.
5. Select **Apply acquisition records** only after reviewing replacements.

Blank imported cells clear existing acquisition fields. Validation is not saving; only the confirmed Apply operation writes the records.

# 13 Printing copy QR labels
Open **Print QR**. Each physical copy needs its own label, even when several copies share a title.

## Individual and selected labels
1. Search by title, author, or copy QR.
2. Find the exact copy number and code.
3. Use its download action to save an individual PNG, or select several copy cards.
4. Use **Select Visible** to select the current page when appropriate.
5. Download the selected-copy PDF and print it clearly.
6. Match each printed label to the corresponding physical book.

Selected PDFs allow up to **1,000 copies**. Select Visible does not select every matching copy on every page.

## All matching copies
Apply a search, then choose **Export all matching** for a ZIP of matching label batches. Use this for larger exports. Wait for progress to finish and check the download. Failed exports preserve the selection and offer **Retry download**.

Never attach the same physical-copy code to different copies or reuse a retired copy's identity. Reprinting a label does not add stock.

# 14 Operating the entrance station
The Entrance Station records attendance. It is separate from account sign in and from loans or returns.

## Unlock and start the camera
1. Open the Entrance Station on the staff-operated device.
2. Enter the authorized staff PIN and select **Unlock Station**.
3. Make the biometric privacy notice visible and follow the approved library process.
4. Select **Start camera** and allow permission.
5. Position the camera for a clear, evenly lit live face.
6. Check the connection indicator and Attendance Log.

Starting the camera is not an individual visitor's consent record. The PIN unlocks attendance scanning but does not sign a member or librarian into their account.

## Record an encounter
1. Ask an enrolled member to approach naturally and face the camera.
2. Wait for recognition and a confirmed entry or exit state.
3. Let the member leave the camera view before another distinct encounter.
4. Review the recorded time and state in Attendance Log.

Repeated frames while the same member remains in view should not be counted as separate visits. A later distinct encounter can toggle the member between inside and outside. Follow the confirmed state, not each camera detection.

An unrecognized, suspended, or uncertain live-face result is not a successful attendance record. Use the library's supervised alternative and assistance process when recognition cannot be completed.

## Pause and recover
Select **Pause camera** when unattended or scanning should stop. Scanning also pauses when the page is hidden. Return and explicitly restart when required.

If the connection fails, do not assume that unseen scans will upload later. There is no durable offline attendance replay. If the PIN fails, ask an authorized librarian to check or replace it in Settings. Replacing the PIN locks older station sessions on a subsequent request.

# 15 Settings and sessions
## Appearance and recovery contact
In librarian **Settings**, use **Switch to light mode** or **Switch to dark mode**. Members have an appearance control in their interface. This preference applies to the current browser.

Use the librarian recovery contact section to add or change email with current-password confirmation. Verify the address with its code before relying on email recovery. The member verification principles in Chapter 6 also apply.

## Replace the station PIN
1. Open librarian **Settings** and find **Entrance station PIN**.
2. Check the configured status.
3. Enter the current librarian password.
4. Enter a new **6 to 12 digit** PIN and repeat it.
5. Select **Save PIN** and wait for confirmation.
6. Privately give it to authorized station staff and unlock each station.

The current PIN is never shown. A librarian can replace it without entering the previous PIN. Keep it separate from account passwords.

## Librarian password
Open the librarian password change page at /librarian/change-password. Enter the current password and a valid new password with confirmation. Follow the 8 to 128 character and digit requirement. Password changes revoke older sessions.

## Sign out
Use **Logout** or the account sign-out control. Wait for confirmation before leaving a shared computer. If sign out is not confirmed, use its retry action. Closing a menu is not sign out. Close camera views when finished.

# 16 Troubleshooting and quick reference
## Common problems
| Problem | Next action |
| --- | --- |
| Sign in fails | Check the portal, full Member ID or email, and password. Use supported recovery or ask staff. |
| Temporary password opens only the change screen | Complete the required password change before other protected tasks. |
| Member name cannot be edited | Ask the librarian about correcting the verified name. |

## Terms
**Title** is a catalog record. **Physical copy** is an individual item issued and returned. **ISBN** identifies a publication, not the library's copy QR. A **library title code** can resolve a title; a **copy QR** identifies a particular copy. A **loan** is a confirmed borrowing transaction. A **ready reservation** can be collected before its deadline; a **queued reservation** is waiting.

## Records and privacy
Use your own account and verify the intended member before staff changes. Keep passwords and PINs private. Keep personal details out of public descriptions and covers. Follow approved processes for private IDs, avatars, biometric enrollment, and deletion.

This edition has no member self-service loan renewal, online fine-payment checkout, book-condition photo workflow, or durable offline synchronization. Use the library counter and approved procedures for requests beyond the available controls.

When asking for help, state the page, action, error, and relevant book or transaction reference through an approved channel. Do not send passwords, verification codes, ID images, or biometric images in an ordinary support message.
