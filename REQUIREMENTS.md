# Rizal Provincial Library System - Requirements

## 1. Problem Statement
The current manual logbook and card-based borrowing process are slow, prone to human error, and make monthly reporting difficult for the librarian.

## 2. Functional Requirements (What the system MUST do)
* **Face Recognition Entrance**: Replace manual logbooks with a biometric "Kiosk" for attendance.
* **Slidable Genre Collection**: Provide a "Netflix-style" browsing experience for the 7,000+ book inventory.
* **QR Code Circulation**: Use QR codes for borrowing/returning books to ensure 100% data accuracy.
* **Automated National Reporting**: Auto-generate statistics for the National Library (popular books, usage trends).
* **Personalized Smart Shelf**: An AI algorithm that suggests books based on user history and overall library popularity.
* **Downloadable Transcript**: Users can download a "Reading Report" for school or personal records.

## 3. User Roles
* **Guest**: Quick face scan for attendance; browse public catalog.
* **Borrower (Member)**: Manage personal account; check due dates; scan face to reserve books.
* **Librarian**: Full inventory control via Excel upload; monitor live traffic; generate monthly circulation reports.
